# Dataset provenance

`raw/demo_jobs.csv` was generated by `src/demo_data.py` using seed 42. It contains 80 fictional postings and one intentional duplicate. Every row is marked `is_demo=true`, with a source identifying the generator. No real employer postings were scraped or copied; no third-party dataset is bundled.

Salaries, locations, skills, and descriptions exercise the application. Their distributions and model scores have no real labor-market interpretation. Repeated description templates make classifier evaluation optimistic.

An initial public-dataset search did not establish a readily reusable source with verified provenance for this build. The project uses the requested demo fallback rather than redistribute uncertain data.

To use real data, follow the README input contract and save `raw/jobs.csv`. Document publisher, exact download URL, download date, license and redistribution terms, population, time period, sampling, and column mappings here. Preserve synthetic flags accurately. A public download alone does not establish permission to republish it.

Do not include secrets or personal contact information in the public portfolio CSV.
