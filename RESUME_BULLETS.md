# Resume bullets

These bullets describe the implemented project. The bundled data is fictional; do not claim real market findings, professional experience, or predictive performance from it.

- Built a Streamlit dashboard with Plotly charts and filters for job roles, locations, work arrangements, and technical skills.
- Developed a pandas pipeline to clean posting text, remove normalized duplicates, handle missing data, and parse comparable USD salary ranges.
- Designed SQLite postings and skills tables and wrote SQL joins, grouped summaries, CASE expressions, and a CTE to analyze skill mentions and combinations.
- Added pytest coverage for data cleaning, skill extraction, SQL analysis, and dashboard filter behavior.
- Implemented an optional TF-IDF and Logistic Regression classification exercise with a held-out split and per-class evaluation, clearly separating synthetic demonstration scores from real-world performance.
